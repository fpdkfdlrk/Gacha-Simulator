# 🎲 ER GGST 가챠 시뮬레이터

이터널리턴 길티기어 스트라이브 콜라보레이션 관련
**토큰 / 카드 교환 / 목표 달성 비용**을 시뮬레이션할 수 있는 웹 시뮬레이터입니다.

---

## ▶ 시뮬레이터 바로가기

👉 **웹에서 바로 실행**
https://fpdkfdlrk.github.io/Gacha-Simulator/

---

## 📌 주요 기능

- 상자 1회 / 5회 / 10회 뽑기 시뮬레이션
- 실제 확률 기반 토큰 획득
- 컬렉션 카드 50장 → 토큰 100개 자동 교환
- 스킨 교환 조건 (450 토큰) 달성 시점 표시
- 올콜렉트 조건 (555 토큰) 달성 시점 표시
- 각 조건 달성 시 **사용 금액 자동 기록**
- 555 토큰 달성 시 추가 뽑기 자동 비활성화
- 뽑기 로그 확인 가능
